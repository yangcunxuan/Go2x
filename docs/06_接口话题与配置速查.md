# 接口、ROS 话题与配置速查

## 巡逻网页 API（8090）

### 查询

- `GET /api/status`：设备、位姿、GO2、服务、任务状态。
- `GET /api/cloud`：当前三维点云抽样。
- `GET /api/navigation/path`：当前 Nav2 规划路线。
- `GET /api/maps`：地图列表与活动地图。
- `GET /api/maps/cloud?name=<地图>`：查看保存的三维地图。
- `GET /api/checkpoints`：巡查点。
- `GET /api/tasks`：积木任务。
- `GET /api/logs/mapping`、`/api/logs/navigation`：页面日志。

### 操作

- `POST /api/mapping/start`、`/api/mapping/stop`
- `POST /api/navigation/start`、`/api/navigation/stop`
- `POST /api/navigation/goal`
- `POST /api/robot/action`：`stand_up` / `stand_down`
- `POST /api/teleop`
- `POST /api/maps/save`、`/api/maps/activate`、`/api/maps/continue`
- `POST /api/checkpoints/save`、`/api/checkpoints/delete`
- `POST /api/tasks/save`、`/api/tasks/run`、`/api/tasks/stop`、`/api/tasks/delete`
- `POST /api/radar/stop`

运动类 API 需要现场确认字段，且会执行状态/温度/定位保护。不要用 curl 绕过页面确认做无人看守测试。

## C12 API（8088）

- `GET /api/status`：双路视频状态。
- `GET /stream/visible`：可见光 MJPEG。
- `GET /stream/thermal`：热成像 MJPEG。
- `GET/POST /api/thermal/palette`：读取/设置调色板。
- 预置点、云台移动和截图接口定义在 `c12_web/server.py`。

## TF/坐标系

- `map_level`：保存地图和网页使用的水平全局坐标。
- `camera_init`：FAST-LIO 起始坐标系。
- `body`：机器狗/雷达机身坐标，Nav2 base frame。
- `map`：兼容别名，当前用静态 TF 与 `map_level` 对齐。
- `livox_frame`：Livox 驱动点云帧。

当前 `map_level -> camera_init` 包含机械倾角修正和重定位平移/偏航。

## 配置生效方式

- `patrol_web/static/*`：刷新浏览器（必要时强制刷新）。
- `patrol_web/server.py`：重启网页 Python 进程。
- `c12_web/server.py`：重启 C12 Python 进程。
- `scripts/nav_motion_bridge.py`、`inside_navigation.sh`、Nav2 配置：停止并重新启动导航。
- FAST-LIO/Livox 配置：停止并重新启动建图/定位，会产生新的起始会话。
- `go2_state_bridge.py`：由 `inside_go2_state_bridge.sh` colcon symlink build 后重启桥。
