## 技术栈

| 层 | 技术 | 用途 |
|---|---|---|
| 系统 | Ubuntu 22.04 | 当前验证主机；后续迁移 Orin NX |
| 容器 | Docker、docker-compose、host network | 固定 ROS 依赖并直连设备网络 |
| ROS | ROS 2 Humble | 话题、TF、Action、消息与进程编排 |
| DDS | CycloneDDS | MID360 域 42、GO2 域 0，按网卡隔离 |
| 雷达 | Livox SDK2、livox_ros_driver2 | MID360S 点云与 IMU |
| 建图 | FAST-LIO2 | 激光惯导里程计、三维累计点云 |
| 导航 | Nav2 | 生命周期、行为树、地图/规划/控制 |
| 全局规划 | NavfnPlanner（A*） | 在占据栅格上生成全局路线 |
| 局部控制 | DWBLocalPlanner | 输出前进/侧移速度并避障 |
| 障碍转换 | pointcloud_to_laserscan | MID360 三维点云投影为 `/scan` |
| 机器狗 | Unitree `unitree_api` / `unitree_go` | LowState、SportState、Sport API |
| 后端 | Python 3 标准库 HTTP Server | Web API、服务进程、文件状态机 |
| ROS 桥 | Python、rclpy、NumPy | 点云、位姿、Action、运动中继 |
| 前端 | HTML、CSS、原生 JavaScript | 单机巡逻控制台 |
| 点云显示 | Canvas/前端三维投影逻辑 | 地图、GO2 箭头、XYZ、Nav2 路线 |
| 任务编排 | Google Blockly | 积木式巡逻任务 |
| 相机 | RTSP、FFmpeg、UDP 私有协议 | C12 双光、云台、预置点、调色板 |

## 网络与 ROS 域

```text
Wi-Fi wlp1s0      192.168.2.42       远程 SSH/网页，不应参与机器人数据
有线 enx...       192.168.123.10     GO2 + MID360 交换机
GO2               192.168.123.161    ROS_DOMAIN_ID=0
MID360S           192.168.123.170    ROS_DOMAIN_ID=42
C12               192.168.144.108    RTSP 554/555，UDP 5000
```

两个 ROS 域通过 `runtime/*.json` 文件和两个 Python 桥间接连接，避免把 GO2 与 FAST-LIO 的 DDS 发现混在同一域/错误网卡上。
