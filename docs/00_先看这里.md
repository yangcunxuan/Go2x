## 当前系统能做什么

1. 接收 MID360S 点云和 IMU。
2. 使用 FAST-LIO2 输出三维累计点云与里程计。
3. 在网页中查看三维点云、机器狗 XYZ、朝向、状态、巡查点和 Nav2 路线。
4. 保存 PCD 三维地图，并生成供 Nav2 使用的 PGM/YAML 平面导航层。
5. 通过网页手动控制 GO2 站立、趴下和移动。
6. 通过 Nav2 规划到巡查点的路线，并将速度指令转为 Unitree Sport API 指令。
7. 查看 C12 可见光/热成像双路视频，控制云台、预置点和热成像调色板。
8. 使用 Blockly 积木组合导航、等待、拍照、预置点和热成像样式任务。

## 必须先理解的技术事实

当前是“3D 感知与建图 + 2.5D 平面导航”，不是完整三维路径规划：

- MID360 + FAST-LIO2 生成、保存和显示三维 PCD。
- `pcd_to_nav_map.py` 将三维 PCD 投影为二维 PGM 占据栅格。
- Nav2/Navfn/DWB 在该平面栅格上规划 GO2 的地面运动。
- 网页仍显示三维地图、三维坐标和规划线路。

这适合地面四足机器人在近似平坦环境巡逻；楼梯、悬崖、跨层路线和复杂坡面仍需要高程图/体素地图、地形可通行性分析或专用三维规划器。

## 安全原则

- 第一次改动控制或导航时必须让狗趴下验证数据，确认后才站立。
- 导航前必须确认位置、朝向、活动地图、点云、当前位置可通行和路线起点一致。
- 不要同时运行手动控制和自主导航。
- 测试时保留遥控器/急停手段，机器狗周围不要站人。
- 不要为“让它动起来”而直接关闭障碍、定位和温度保护。
